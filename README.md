# Shivaay Library

Welcome to the **Shivaay Library** project! 

This is a web-based application for managing a library. It includes features for both users (browsing the library, gallery, and memberships) and administrators.

## 🚀 Features
- **Home Page**: Overview of the library.
- **Admin Panel**: For managing library resources.
- **Gallery**: Visual showcase of the library facilities.
- **Membership**: Information on how to join.
- **Contact**: Reach out to the library directly.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Firebase (Firestore for database rules)

## 📂 Project Structure
- `index.html` - Main landing page.
- `admin.html` & `admin.js` - Administrator dashboard and logic.
- `style.css` & `admin.css` - Styling for the application.
- `client/` and `server/` - Directory structure for client and server-side code.

## 💻 Getting Started
To view this project locally:
1. Clone the repository to your local machine.
2. Open `index.html` in your favorite web browser.
